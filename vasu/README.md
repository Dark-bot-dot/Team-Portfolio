# Vasu Kiran Naladala — Personal Portfolio

Five-page responsive HTML5, CSS3, JavaScript, Bootstrap 5 portfolio, updated from the supplied resume.

## Run locally

1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html` in a browser or use the Live Server extension.
4. Bootstrap 5 loads from a CDN, so internet access is needed for Bootstrap styling and its mobile menu.

## Pages

- `index.html` — introduction and overview
- `about.html` — education, CGPA and scholarships
- `projects.html` — five projects and verified resume-listed links
- `skills.html` — resume-listed languages, libraries and tools
- `contact.html` — email, GitHub, phone and contact form

## Contact form

The form uses HTML5/JavaScript validation and opens a `mailto:` draft in the visitor's configured email app. It does **not** deliver messages automatically. For production submissions, connect a backend or form service.

## Content notes

All personal information is sourced from the uploaded resume. Missing project URLs were not fabricated. The LinkedIn short URLs for the Contact Manager and Stock Trading Simulator live apps are included exactly as provided in the resume. The resume does not list a personal LinkedIn profile.

## Technologies

HTML5 semantic tags, CSS3 Grid/Flexbox and media queries, Bootstrap 5, vanilla JavaScript.
