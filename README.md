# Team Portfolio Hub - CS 311 Web Programming Project

## Project Overview
A collaborative multi-page portfolio project built by 6 students. Each team member designed and developed their own personal portfolio website with a unique layout and style. All portfolios are linked together through a common landing page (Team Hub).

## Technologies Used
- **HTML5**: Semantic elements (header, nav, section, article, footer)
- **CSS3**: Grid layout, Flexbox, media queries, transitions
- **Bootstrap 5**: Responsive components and utility classes
- **JavaScript**: Form validation, smooth scrolling

## How to Run
1. Download or clone the project folder.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Edge).
3. Click on a team member's card to view their individual portfolio.
