The Concept

Not one portfolio.
Six of them.

The brief was simple: build a personal portfolio. But we asked — what if each member built their own, fully independent site, while a central Team Hub connected all six together?

Every portfolio is a reflection of that person. Different stacks, different aesthetics, different stories — unified by one landing page.

Design Philosophy

Every site tells a different story

We each chose our own visual language — and cross-pollinated ideas.

🌑 Dark gradient aesthetic

Ritvik and Vasu both run deep dark themes — Ritvik's purple gradients, Vasu's navy glass-cards with blur effects. Dark backgrounds let the content pop.

🔮
🌊

📰 Editorial warmth

Mohhet's portfolio uses a warm, editorial style — bold 2px borders, offset box-shadows, and coloured card backgrounds. Gave us ideas for card hover states across the team.

📰
🌸

🎯 Minimal single-pager

Mohith's clean single-page approach with Font Awesome icons showed how much personality you can pack into one scrollable page without overloading the user.

☀️ Theme switching

Vikas built a full dark/light toggle using Tailwind CSS — a neat touch that influenced how we thought about accessibility and user preference across the project.

The Magic Ingredient

Ideas that jumped portfolios

🎨

Colour-coded members

Each person has their own accent colour — purple, teal, amber, rose, blue, green. Used in the Team Hub cards and carried through each individual site.

✨

Hover lift animation

Mohhet's editorial box-shadow offset cards inspired the hover lift used on Team Hub member cards — a subtle translateY(-6px) + shadow.

🌙

Dark-first philosophy

Vikas's light/dark toggle and Vasu's deep navy convinced the team that dark-first wasn't just a preference — it was a design statement that made content stand out.

📌

← Team Hub nav link

Every single portfolio page — all 21 HTML files — has a persistent "← Team Hub" link in the navbar. Click anywhere, always find your way back.

📱

Mobile responsive

Bootstrap 5 grid + CSS clamp() for fluid type ensures every portfolio works from 320px mobile to 2K desktop — zero extra media query bloat.

🚀

Live features

Not just static pages — Ritvik's portfolio has a working contact backend (Express + Nodemailer) and a deployed NLP app link. Real, functional.

The Glue

The Team Hub

The landing page isn't just a links page. It's a statement. Dark gradient full-viewport hero, 6 colour-coded member cards, smooth hover animations, and a scrolling navbar.

  • → Full-screen hero with radial gradient and animated scroll cue
  • → 6 cards, each a distinct colour — click to enter that member's world
  • → Display order: Ritvik → Vasu → Mohhet → Mohith → Bharath → Vikas
  • → Pure Bootstrap 5 grid + custom CSS — no frameworks beyond that

Takeaways

What we actually learned

01

Code reviews happen naturally

When you can literally open a teammate's HTML file and read it, you start borrowing ideas and catching patterns — without any formal review process.

02

Design is a conversation

Mohhet's editorial cards, Vikas's theme toggle, Vasu's glass morphism — none of these were planned centrally. They emerged and spread organically.

03

Pure frontend is enough

No build tools. No frameworks beyond Bootstrap and Tailwind. Just HTML, CSS, and vanilla JS. And we shipped 21 pages, a working backend, and a live deployed app.
