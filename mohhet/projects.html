PROJECT 01

Sentinel

  • YOLOv8
  • ONNX
  • FastAPI
  • React

Live demo · Code

Spots missing safety gear in images using YOLOv8. It runs in the browser, so images never leave the device.

  • A 10-class YOLOv8n detector for personal protective equipment, scoring 0.744 mAP@50.
  • Exported to ONNX and run with onnxruntime-web, so images stay on the user's device.
  • A pipeline of detect, track, rule-check and incident, sent live over WebSockets.
  • 57 REST endpoints with JWT and role-based access, tested and shipped with Docker Compose and CI.
PROJECT 02

Clarity

  • LangChain
  • FAISS
  • FastAPI
  • React

Live demo · Code

A research prototype that answers clinical questions with cited evidence, using retrieval-augmented generation (RAG).

  • Retrieval over curated guidelines and PubMed, returning answers with cited evidence.
  • Extracts entities, negation, vitals and lab values from clinical text.
  • Logistic-regression models for diabetes and heart disease, built with scikit-learn.
  • Falls back to a rules mode when the language model is unavailable.
